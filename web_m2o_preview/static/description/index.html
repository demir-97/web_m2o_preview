Many2one Hover Preview — See Who's Behind a Field Without Leaving the Form

Adds a small eye icon next to any many2one field using the many2one_preview widget. Hover it (or tap it on a touch device) and a small card pops up with the linked record's name, an optional image, and any extra fields you choose.

✓ Odoo 17.0✓ Odoo 18.0✓ Odoo 19.0

How it works

  1. Add widget="many2one_preview" to a many2one field in a view (see Usage below).
  2. Open a record that has that field filled in.
  3. Hover the small eye icon next to the field — a card pops up with the linked record's details.

Why this module?

Opening a related record just to check its email or city breaks your flow and loses your place on the current form. One hover icon settles it in place — no navigation, no extra click.

What stays untouched

  • The normal many2one behavior — search, quick create, opening the record.
  • The preview is purely additive and read-only.

Technical

One new field widget (many2one_preview, extends the core Many2OneField) plus a small popover component. No models, no views, no security rules shipped — nothing changes until you add the widget yourself.

Usage

<field name="partner_id" widget="many2one_preview"
       options="{'preview_fields': 'email,phone,city', 'preview_image_field': 'avatar_128'}"/>

preview_fields (optional): comma-separated technical field names of the linked model to show in the card. preview_image_field (optional): technical name of an image field (e.g. avatar_128). Omit it to show no image.

Frequently asked questions

Does it change how the field is saved?
No — the preview is read-only and purely additive. Search, quick create and opening the record all work exactly as before.
Can I use it on any many2one field?
Yes, on any model — just add widget="many2one_preview" to the field in a form view.
What if I don't set an image field?
Leave preview_image_field out of the options and the card simply shows no image, only the name and the fields you listed.
